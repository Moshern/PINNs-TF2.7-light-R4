# PINNs-TF2.7-light-R4

Physics-informed neural networks (PINNs) for reconstructing pulsatile flow fields in straight and curved pipes from sparse velocity data.

This repository accompanies the manuscript:

> **Reconstruction of pulsatile flow in curved pipes using physics-informed neural networks**
> Xingchao Zhang, Fan Wu, Yunfan Yang, Hongping Wang, Shizhao Wang
> Submitted to *European Journal of Mechanics - B/Fluids* (manuscript no. EJMFLU-D-26-00743).

The PINN embeds the incompressible Navier–Stokes equations into the loss function and reconstructs the velocity and pressure fields simultaneously from velocity measurements (e.g., PIV-type data).

## Reproducible example

The data included here correspond to a **two-dimensional curved pipe at Re = 1000, Wo = 10, β = π/32**, in which the PINN reconstructs the velocity and pressure fields from sparse velocity data. The same code structure applies to the other cases in the manuscript (2D/3D straight and curved pipes) by switching the data file and `savename`.

| File | Description |
|---|---|
| `data/bendpipe/2dWo10Bpi32_reslu40_noise0_pinn.mat` | Training data for the 2D curved-pipe case (Re = 1000, Wo = 10, β = π/32) |

Note: pre-trained weights are not included in this repository; they are generated by running `train.py` (which saves weights under `weights/2dWo10Bpi32_13_128/`, the same `savename` that `predict.py` loads). Pre-computed prediction outputs (`predict_results/`) are regenerated by running `predict.py`.

## Directory structure

```
.
├── train.py                     # Training entry (2D curved-pipe case)
├── predict.py                   # Prediction entry (loads trained weights, predicts on the mesh)
├── datagenerator.py             # Data loading
├── pinns_2d.py                  # 2D PINN model
├── funcs.py                     # Helper functions (LevenbergMarquardt, generate_dataset)
├── maps.py                      # Network architecture (ResNet)
├── userbackend.py               # TensorFlow backend / GPU configuration
├── autograd-minimize/           # Third-party dependency (required by pinns_2d)
├── data/
│   └── bendpipe/
│       └── 2dWo10Bpi32_reslu40_noise0_pinn.mat   # 2D curved-pipe training data (Re=1000, Wo=10, β=π/32)
└── (weights/ is created by train.py and is not tracked)
```

## Environment

The code was developed and tested with:

- Python 3.9
- TensorFlow 2.7 (GPU)
- CUDA 11.x / cuDNN 8.2
- numpy, scipy, h5py, matplotlib, sympy

Install the required packages:

```bash
pip install numpy scipy h5py matplotlib sympy tensorflow==2.7
```

The repository vendors the `autograd-minimize` package (used by `pinns_2d.py` for BFGS-type fine-tuning). It is imported directly from this directory, so no separate installation is needed. If you prefer to install it from PyPI instead, run:

```bash
pip install autograd-minimize
```

and remove the vendored `autograd-minimize/` folder (or keep it; the import will use the installed package).

## Usage

The weights are not included in this repository; they are generated by `train.py` and loaded by `predict.py` under the same `savename` (`2dWo10Bpi32_13_128`), so the full pipeline is `train.py` followed by `predict.py`.

1. **Train the model**

   The training setup is described in `train.py` (2D curved-pipe case, 13 hidden layers × 128 neurons, adaptive loss weighting, Adam + optional L-BFGS). Run:

   ```bash
   python train.py
   ```

   After training completes, the weights and normalization parameters are saved in `weights/2dWo10Bpi32_13_128/`. Training requires a GPU and takes on the order of several hours.

2. **Generate predictions**

   The model is loaded with the `NS2D_UnSteady_PINNs` class from `pinns_2d.py`:

   ```python
   savename = '2dWo10Bpi32_13_128'
   save_file = './weights/' + savename + '/' + savename
   domain = scipy.io.loadmat(save_file + '_paras.mat', squeeze_me=True)
   norm_paras = domain['norm_paras']
   hp = {'layers': [3] + 13 * [128] + [3],
         'ExistModel': 1, 'train': False, 'maptype': 'rnn',
         'savename': savename, 'Re': 1000.0, 'alpha': 1.0,
         'norm_paras': norm_paras, 'tf_epochs': 6000, 'tf_batch_size': 10000,
         'initial_epoch': 0, 'init_lr': 1.0e-3,
         'bfgs_epochs': 0, 'bfgs_batch_size': 10000,
         'lm_epochs': 0, 'lm_batch_size': 200}
   pinn_model = NS2D_UnSteady_PINNs(hp)
   ```

   The network maps any spatiotemporal coordinate `(t, x, y)` in the domain to `(u, v, p)`. To reproduce the manuscript prediction, run:

   ```bash
   python predict.py
   ```

   which loads the trained weights (`weights/2dWo10Bpi32_13_128`) and predicts `u`, `v`, `p` and the Navier–Stokes residuals on the full 2D mesh, saving the results to `predict_results/`.

## Reproducing the parameter sweep / data-coverage studies

The manuscript also reports a Womersley-number / amplitude-ratio parameter sweep (`Wo = 0–15`, `β = π/64–π/8`) and a comparison of four training-data compositions (single-plane, assumed-parabolic inlet, orthogonal cross-plane, and full 3D). The 2D curved-pipe case included here is representative of the approach. The training/prediction routines for the additional cases follow the same code structure as the provided example, by switching the training data file (in `train.py`) and `savename`. The associated CFD data files for those cases are large (>100 MB) and are not included in this repository. They can be requested from the corresponding author.
